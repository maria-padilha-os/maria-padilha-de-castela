# Build layout

The canonical archiso profile for the private Maria Padilha de Castela image is
[`../iso/`](../iso). Build it with [`../build.sh`](../build.sh) from inside an
Arch Linux container.

`build/archiso/profile` is a compatibility symlink to `iso/` for older notes
that referenced a `build/archiso/profile` path. Do not create a second profile
there; edit the files under `iso/` only.

The image is private. Do not publish, upload, mirror, or redistribute it.
