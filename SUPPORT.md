# Supporting Maria Padilha

Maria Padilha is free software under GPL-3.0-only. Donations are optional: no
feature is paywalled, no build is held back, and there are no ads or trackers.

[![Sponsor on GitHub](https://img.shields.io/badge/Sponsor-GitHub-ea4aaa?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/Mateus-M-Reis)

**[Sponsor @Mateus-M-Reis on GitHub](https://github.com/sponsors/Mateus-M-Reis)**

Castela is part of the Maria Padilha project. Its source is public; build and
release artifacts remain private.

The canonical support page is [maria-padilha-de/SUPPORT.md](https://github.com/maria-padilha-os/maria-padilha-de/blob/main/SUPPORT.md).

## Other ways to help

- Star the repositories and report bugs with logs; that is useful work too.
- If you want paid support or a specific integration, open an issue and say so.
- Additional funding platforms can be added to this repository's
  `.github/FUNDING.yml`.

The money, when it exists, goes to hardware, hosting, and development time —
not to closing the source.
