# Verified public keys

Place only verified **public** key files here, one file per key, named after the
key fingerprint. Do not place private keys, revocation certificates, keyring
exports, or passphrases in this directory.

Current builds use the `archlinux-keyring` and `blackarch-keyring` packages for
trust. `blackarch.gpg` is the verified public BlackArch keyring pinned in
`../trusted-keyrings.txt`; its fingerprints are in
`../blackarch-fingerprints.txt`.
